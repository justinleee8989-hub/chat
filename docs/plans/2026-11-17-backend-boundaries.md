# 后端边界与兼容性修复

范围已由用户确认：修复消息可见性、通话协议、查询/存储压力、表情策略，保持 UI、旧消息和现有体验数据。

- [x] 消息增强读取：原始消息逐条按当前用户验证；持久化可靠 seq；旧记录按用户可见历史查找，不使用管理员搜索绕过权限。未知/不可见不返回，失败关闭。
- [x] 协议：独立 callprotocol 包，保留 v1/v2 文本前缀及字段，不改客户端显示。
- [x] 查询：独立 admission/并发控制，已读明细请求去重限流、全局8个上游调用、取消及时退出，无可见性缓存。
- [x] RTC Redis：无变化不 SET，保留 WATCH 原子性和 TTL，兼容原 key/数据；全局原子预约保留，避免危险数据迁移。
- [x] 表情策略：可配置白名单，默认8种保持不变，旧回应可取消。
- [x] 隔离测试、race、构建，部署补丁同步；不更改原体验数据、不推送。
